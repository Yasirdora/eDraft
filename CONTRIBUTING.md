# Contributing

Thank you for taking an interest in eDraft.

This repository holds documentation, example files and images. The application
source code is private, so there is no build to run here and no source to send a
change against. **Pull requests that add application code are not accepted.**

What is useful:

## Report a problem

Open an issue using the bug report form. If it concerns a file, say which format
it was and where it came from; the behaviour of a Final Draft document and a
Fountain file can differ.

If you are reporting something in these documents — a wrong statement, a broken
link, an example that does not do what the text says — that is just as welcome.

## Suggest an idea

Open an issue using the idea form. Describe the problem you are trying to solve,
and what you do today instead.

So is saying what should *not* be built.

## Correct the documentation

Documentation corrections are the one place a pull request is welcome. Keep it
to the point: what is wrong, and what it should say.

## Report a security issue

Do not open a public issue. See [SECURITY.md](SECURITY.md) for the private
channel.

## Collaboration and research licences

eDraft is open to collaboration with screenwriting professionals, educators,
researchers and developers. Research licences are available on request. Write to
[edraft@ysr.design](mailto:edraft@ysr.design).

## What this project will not do here

The application source is private by decision. Requests to open it are read;
this repository is not where that changes, and issues asking for it are closed
with a pointer to this section.

## Language

Enquiries in English, please.
