# Changelog

Notable changes to eDraft are recorded in this file, in the shape described by
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 1.0.0 — 8 October 2026

The first public release, on the App Store for macOS 26 and later.

### Added

- Screenplay editing with element formatting as it is typed: scene headings,
  action, character cues, dialogue, parentheticals and transitions.
- Tab and Return choreography, character prediction, find and print.
- Final Draft document and Fountain import and export, in both directions.
- PDF and Word export. A PDF carries its own source, so reopening one restores
  the script rather than re-deriving it from the page.
- Import from Word documents and plain text, with every unsure line reported
  before the import commits and the writer's override taken as final.
- Title page as a sheet, the character thread as the Cast tab, and a scene
  navigator derived from the script.

### Known gaps

- Revision colours, locked pages and scene numbering as commands are not in
  this release. They are the production layer, and they are next.
